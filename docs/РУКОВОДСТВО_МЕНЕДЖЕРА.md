# Руководство менеджера — CRM «Дом-Мастер»

**Для кого:** менеджеры ОП  
**CRM:** http://194.67.103.144:5001  
**Telegram-бот:** `@stroyka_KP_bot`  
**Дата:** 12.08.2026

---

## 1. Зачем CRM

После звонка вы:

1. создаёте сделку и вставляете транскрибацию;
2. видите, каких полей не хватает для КП;
3. дособираете данные (звонок / правка);
4. генерируете КП тёплого контура;
5. утверждаете и отправляете клиенту (Email и/или Telegram).

Цена в КП: **площадь × 41 000 ₽/м²** (стандарт «тёплый контур»).

---

## 2. Вход

1. Откройте http://194.67.103.144:5001  
2. Войдите логином/паролем (выдаёт администратор).  
3. Разделы: **Дашборд** · **Сделки**.

На телефоне: меню «☰», список сделок — карточками, в карточке сделки — кнопки внизу экрана.

---

## 3. Рабочий день — короткий сценарий

```text
Звонок → Новая сделка → вставить протокол
        → смотреть % заполнения
        → если < 80% — доспросить по скрипту
        → Сгенерировать КП → Утвердить → Email / Telegram
```

### 3.1. Создать сделку

1. **Сделки** → **Новая сделка**  
2. Укажите имя клиента (если известно).  
3. Вставьте текст протокола / транскрибации (или загрузите `.txt`).  
4. Сохраните.

Система сама вытащит телефон, email, площадь и другие поля.

### 3.2. Проверить готовность

В списке и в карточке видно **% заполнения**:

| % | Значение | Действие |
|---|----------|----------|
| **≥ 80%** | Можно генерировать КП | Кнопка «Сгенерировать КП» |
| 50–79% | Нужны уточнения | Открыть «Недостающие данные» |
| &lt; 50% | Много пропусков | Перезвонить по скрипту |

### 3.3. Дособрать данные

Если полей не хватает:

1. Откройте сделку → **Недостающие данные** (или иконка ⚠ в списке).  
2. Там список пробелов и **готовые вопросы** для клиента.  
3. После звонка — **Редактировать** и внесите ответы.  
4. % пересчитается автоматически.

### 3.4. Сгенерировать КП

1. В карточке откройте вкладку **КП**.  
2. Нажмите **Сгенерировать КП** (подтверждение в окне).  
3. Дождитесь спиннера (иногда 1–2 минуты).  
4. Скачайте PDF-черновик.

### 3.5. Утвердить и отправить

1. **Утвердить** — водяной знак «УТВЕРЖДЕНО».  
2. Отправка:
   - **Email** — основной канал (нужен email клиента и настроенный SMTP).  
   - **Telegram** — опция (клиент должен привязать чат по ссылке из карточки).

Не отправляйте черновик клиенту без утверждения.

## 4. Обязательные поля для КП (эталон)

Нужны **все 7** (порог генерации — **80%**, то есть минимум 6 из 7):

| Поле | Пример вопроса клиенту |
|------|------------------------|
| Телефон | Удобный номер для связи? |
| Email | На какой email отправить КП? |
| Участок | Участок есть? Размер и расположение? |
| Площадь | Какую площадь дома планируете (м²)? |
| Материал стен | Подтверждаем газобетон (стандарт компании)? |
| Сроки старта | Когда старт строительства (месяц/сезон, год)? |
| Финансирование | Свои средства / ипотека / маткапитал? |

**Не обязательно для %:** Telegram, бюджет клиента.  
**Считается автоматически:** Стоимость ТК = площадь × 41 000 ₽.

Подробный эталон: [`knowledge_base/etalon_protocol.md`](../knowledge_base/etalon_protocol.md).

## 5. Статусы сделки

Меняйте вручную на вкладке **Основное** (кнопки статуса):

| Статус | Когда ставить |
|--------|----------------|
| Новая | Только создали |
| Неполные данные | Ждём уточнений от клиента |
| КП готово | Черновик/утверждённое КП есть |
| КП отправлено | Ушло клиенту |
| Завершена | Сделка выиграна / закрыта успешно |
| Проиграна | Отказ / неактуально |

Вкладка **История** — журнал действий (создание, правки, генерация, отправка).

## 6. Telegram-привязка клиента

Чтобы слать КП в Telegram:

1. В карточке сделки скопируйте **ссылку привязки**.  
2. Отправьте клиенту (WhatsApp / SMS / голосом).  
3. Клиент открывает ссылку и нажимает Start у бота.  
4. В карточке появится `chat_id · привязан`.  
5. После утверждения КП нажмите **Telegram**.

Без привязки кнопка Telegram будет неактивна — используйте Email.

Бот для менеджеров (отдельный сценарий с транскрибацией в чате): `@stroyka_KP_bot`.

## 10. Частые вопросы

**Почему нет кнопки «Сгенерировать КП»?**  
Заполнение &lt; 80%. Откройте «Недостающие данные» и дособерите поля.

**Генерация долго крутится / ошибка сети**  
Подождите или нажмите ещё раз. Система может собрать КП без AI (шаблон), если долгий запрос оборвался.

**Email не уходит**  
Проверьте email в карточке. Если ошибка SMTP — напишите администратору (настройка почты на сервере).

**Telegram неактивен**  
Клиент не привязал бота. Скопируйте ссылку привязки из карточки.

**Неверный % или поля**  
Правьте вручную: **Редактировать**. Парсер может ошибиться на кривом тексте протокола.

**Забыл пароль**  
Только через администратора CRM.
