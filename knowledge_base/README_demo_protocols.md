# Демо-протоколы для тестирования системы

## Цель

Эти протоколы созданы для демонстрации работы CRM и проверки логики
определения полноты данных относительно эталона (`etalon_protocol.md`).

Порог генерации КП: **≥ 80%** (`ETALON_KP_THRESHOLD`).

## Описание протоколов

### 1. [demo_protocol_1.md](demo_protocol_1.md) — полный (100%)

| | |
|---|---|
| **Статус** | Готов к генерации КП |
| **Ожидаемый %** | **100%** |
| **Особенности** | Все обязательные поля эталона заполнены |
| **Использование** | Идеальный сценарий: бейдж «Готово к КП», кнопка генерации доступна |

Клиент: Сергей · телефон, email, Telegram, участок, бюджет, площадь, кирпич, май 2026, ипотека.

### 2. [demo_protocol_2.md](demo_protocol_2.md) — частичный (≈44%)

| | |
|---|---|
| **Статус** | Требует значительной доработки |
| **Ожидаемый %** | **44%** (grade low) |
| **Особенности** | Есть телефон, email, бюджет, площадь; нет участка, материала, сроков, финансирования, Telegram |
| **Использование** | Список недостающих полей + скрипт дозвона |

### 3. [demo_protocol_3.md](demo_protocol_3.md) — почти готов (≈78%)

| | |
|---|---|
| **Статус** | Рекомендуем дособрать до порога КП |
| **Ожидаемый %** | **78%** (grade mid) |
| **Особенности** | Почти всё есть; не хватает Telegram и финансирования |
| **Использование** | Пороговое состояние: КП ещё недоступно (&lt; 80%) |

### 4. [demo_protocol_4.md](demo_protocol_4.md) — мало данных (≈0%)

| | |
|---|---|
| **Статус** | Критически недостаточно |
| **Ожидаемый %** | **0%** (grade low) |
| **Особенности** | Только имя клиента; контактов и параметров стройки нет |
| **Использование** | Красный индикатор, полный список уточнений |

## Как использовать

### Через интерфейс

1. Откройте список сделок: `/deals/`
2. Нажмите **«Загрузить демо»** (существующие сделки будут заменены)
3. Проверьте бейджи эталона: 100% / 44% / 78% / 0%
4. На неполных сделках откройте модалку / страницу «Недостающие данные»
5. При необходимости нажмите **«Очистить»**

### Через CLI / сервер

```bash
# локально
python3 web_app/load_demo_protocols.py --yes --clear

# полный сброс на VPS
./scripts/reset_and_load_demo.sh
```

### API (нужна авторизация)

- `POST /admin/load-demo` — бэкап + очистка + 4 демо
- `POST /admin/clear-deals` — удалить все сделки

## Что проверить

| Сценарий | Протокол | Ожидание |
|---|---|---|
| 100% → КП | №1 | `can_generate_kp = true` |
| ~50% → missing | №2 | список пробелов, КП заблокировано |
| ~70% → дособрать | №3 | mid, рекомендация допорога 80% |
| пустой звонок | №4 | low / 0%, полный скрипт дозвона |
