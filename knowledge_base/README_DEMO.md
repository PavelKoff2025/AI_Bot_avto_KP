Эталон: 7 обязательных полей (телефон + **email** обязательны; Telegram опционален).

| Файл | Сценарий | Ожидаемый % | КП |
|---|---|---|---|
| [demo_protocol_1.md](demo_protocol_1.md) | Полный комплект | **100%** | можно |
| [demo_protocol_2.md](demo_protocol_2.md) | Много пропусков | **≈43%** | нельзя |
| [demo_protocol_3.md](demo_protocol_3.md) | Нет финансирования | **≈86%** | можно |
| [demo_protocol_4.md](demo_protocol_4.md) | Почти пустой звонок | **0%** | нельзя |

```bash
cd web_app && python3 clear_test_data.py --yes
```
